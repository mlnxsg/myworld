# 我的世界

一个在浏览器里运行的个人工作台。把正在做的事放在白板上，随手记下想法和参考资料，做完后留下复盘。

## 有什么功能

- **做事**：双击白板新建项目，拖动文件夹自由摆放。项目内可以记录目标与提醒，给待办估算工作量，并按已完成的分数查看进度。右上角的「我的日常」可以记日常安排。
- **待办（todo）**：先记下还没归入项目的事项，用标签整理。确定要在哪个项目做之后，可以选定项目和工作量，再把事项转进去。
- **归档区**：结束项目时可以写复盘。归档后仍能回看项目，也能把它恢复到白板。
- **记录与日记**：集中查看项目里的想法和独立的随手记。随手记可以选择日期补写，左侧日记按天查看。
- **Ref 库**：集中保存文字、链接和图片，可以关联项目，也可以保留为独立资料，并标记为已查看。
- **经验总结**：记下值得回顾的经验。可以只写文字，也可以附上图片，用标签查找。

## 本地运行

建议使用 Node.js 22（22.12 或更新的 22.x 版本）。

```bash
git clone https://github.com/mlnxsg/myworld.git
cd myworld
npm ci
npm run dev
```

打开 [http://localhost:5173](http://localhost:5173)。平时请用同一个浏览器和网址打开，浏览器会按网址分别保存数据。

## 数据与备份

- 当前版本使用 IndexedDB 保存文字和图片，记录留在浏览器里。换设备、浏览器或访问网址时，可以通过右上角的「备份」菜单导出并导入 JSON。**导入会覆盖当前数据。**
- 使用 `npm run dev` 时，页面打开后会尝试自动备份，之后每 10 分钟备份一次。同一天会覆盖同一个文件。备份目录在 [`backup-plugin.ts`](backup-plugin.ts) 的 `BACKUP_DIR` 中配置。
- `npm run build` 生成的 `dist/` 可以部署到静态托管平台。静态部署仍然使用浏览器本地存储，备份通过菜单手动导出。

## 开发

项目使用 React、TypeScript、Vite、Tailwind CSS 和 Dexie。界面组件在 `src/components/`，数据读写集中在 [`src/db.ts`](src/db.ts)。

```bash
npm test          # 运行测试
npm run lint      # 检查代码
npm run build     # 构建静态文件
```
